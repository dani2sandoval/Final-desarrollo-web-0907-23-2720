Prompts utilizados

Prompt 1
Dame la arquitectura necesaria para crear una web app para reservar salas de una biblioteca y propón una estructura sencilla con Node.js Sequelize SQLite React y sesiones mediante cookies.

Prompt 2
Ayúdame a crear el backend con un login un listado de salas y un formulario para registrar reservas.

Prompt 3
Agrega una validación en el backend para impedir que una sala tenga reservas con horarios solapados.

Prompt 4
Configura la sesión para que expire después de 30 minutos de inactividad y envía la información mediante una cookie.

Prompt 5
Crea un frontend básico en React con una pantalla de login un formulario de reservas y una tabla para mostrar las reservas registradas.

Prompt 6
Haz que el frontend envíe la cookie en cada solicitud y regrese al login cuando el servidor responda con un error 401.

Prompt 7
Ayúdame a probar el inicio de sesión la creación de reservas el bloqueo de horarios solapados y el cierre de sesión.

Prompt 8
Ayúdame a identificar y corregir los errores encontrados durante la instalación y las pruebas del proyecto.
